# Smart Mechatronics Quiz App

## Project Overview

The Smart Mechatronics Quiz App is a Python-based console application designed to test and improve knowledge of mechatronics concepts.

The program provides multiple-choice questions covering beginner, intermediate, and advanced topics in areas such as electronics, sensors, automation, robotics, PLCs, control systems, and mechanical systems.

The application randomly selects questions, shuffles answer options, tracks performance, and provides feedback after completion.

---

## Features

- User name registration
- Three difficulty levels:
  - Beginner
  - Intermediate
  - Advanced
- Random question selection
- Randomized answer options
- 20-question database per difficulty level
- Timed questions
- Automatic score calculation
- Percentage and grade evaluation
- Personalized performance messages
- Review of incorrect answers
- Replay option

---

## Technologies Used

- Python 3
- Random module
- Time module

## How To Run

### Requirements

- Python 3 installed on your computer

### Steps

1. Download or clone this repository.

2. Open the project folder.

3. Run the program:

```
python mechatronics_quiz.py
```

4. Follow the instructions displayed in the terminal.
